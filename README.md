# BILI-Blacklist
BILIBAN - B站用户屏蔽黑名单备份

#黑名单内容划分

##二游
###崩铁内鬼相关
存放崩铁内鬼相关账号，通过封面、标题和视频内容判断，可能存在编造虚假内鬼信息的账号，如封面、标题无特别标注不会进行区分，一概划分到此分组
###原神内鬼相关
存放原神内鬼相关账号，通过封面、标题和视频内容判断，可能存在编造虚假内鬼信息的账号，如封面、标题无特别标注不会进行区分，一概划分到此分组
###绝区零内鬼相关
存放绝区零内鬼相关账号，通过封面、标题和视频内容判断，可能存在编造虚假内鬼信息的账号，如封面、标题无特别标注不会进行区分，一概划分到此分组
###内鬼二创
主要存放使用内鬼素材制作的二创，如未公布的模型等
###节奏狗、水军、内鬼厨等
主要存放带节奏、刷固定话术、传播内鬼等，属于兜底分组可能继续扩展内容，主要针对社区内的ky、拉踩、带节奏等
###退游哥
主要针对发布退游加截图的形式的评论，往往扎堆出现，疑似水军，可能考虑合并到上一条

##UP
###低创、盗视频等
主要存放一些盗视频等up和低创up，低创目前包括：牢图up、贴吧等其他社区的帖子视频up
###标题党
故意使用与内容不符的标题的up
###垃圾
一些垃圾信源、营销号up

##广告
###垃圾信息
主要是存在于评论区的广告与诈骗信息

##其他
###弱智
一些智力显著低于正常人的群体，表现为选择性失明、理解障碍、常使用滑坡谬误、稻草人谬误等的群体等
###水军
一些其它水军
###台独
一些台独分子，可能考虑删除或改为键政等方案
###测试
测试分组

##PS
黑名单可能存在片面的情况，因为在因为某一分组屏蔽后会屏蔽其相关内容，可能导致可能应该存在于多个分组中的对象最终只存在于一个分组，所以尽可能全开以获得最佳体验
