# 黑名单内容划分

## 二游

### 崩铁内鬼相关

存放崩铁内鬼相关账号，通过封面、标题和视频内容判断，可能存在编造虚假内鬼信息的账号。

如封面、标题无特别标注，不会进行区分，一概划分到此分组。

### 原神内鬼相关

存放原神内鬼相关账号，通过封面、标题和视频内容判断，可能存在编造虚假内鬼信息的账号。

如封面、标题无特别标注，不会进行区分，一概划分到此分组。

### 绝区零内鬼相关

存放绝区零内鬼相关账号，通过封面、标题和视频内容判断，可能存在编造虚假内鬼信息的账号。

如封面、标题无特别标注，不会进行区分，一概划分到此分组。

### 内鬼二创

主要存放使用内鬼素材制作的二创内容，例如使用未公布模型等素材制作的视频。

### 节奏狗、水军、内鬼厨等

主要存放带节奏、刷固定话术、传播内鬼等账号。

此分组属于兜底分组，后续可能继续扩展内容，主要针对社区内的 KY、拉踩、带节奏等行为。

### 退游哥

主要针对发布「退游 + 截图」形式内容的评论。

此类评论往往扎堆出现，疑似存在水军行为，后续可能考虑合并到上一分组。

---

## UP

### 低创、盗视频等

主要存放盗视频、低创等 UP。

目前低创包括：

* 牢图 UP
* 搬运贴吧等其他社区帖子制作视频的 UP
* 其他低创内容

### 标题党

故意使用与实际内容不符的标题，以标题吸引用户点击的 UP。

### 垃圾

主要存放一些低质量信源、营销号等 UP。

---

## 广告

### 垃圾信息

主要存放存在于评论区中的广告、诈骗等信息。

---

## 其他

### 弱智

用于存放一些存在明显理解障碍、选择性失明、常使用滑坡谬误、稻草人谬误等行为的账号。

### 水军

存放其他类型的水军账号。

### 台独

存放相关账号。

> 该分组后续可能考虑删除，或调整为更宽泛的「键政」等分类。

### 测试

用于测试的分组。

---

## PS

黑名单分类可能存在一定的片面性。

由于屏蔽某一分组后，其相关内容也会被一并屏蔽，因此一个对象实际上可能同时符合多个分组的条件，但最终可能只被归入其中一个分组。

因此，**建议尽可能开启全部分组，以获得最佳使用体验。**
